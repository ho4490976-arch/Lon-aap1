## 🎯 **About**

**FamilyLoan** is a complete loan management platform that allows users to:
- ✅ Apply for loans online
- ✅ Calculate EMI instantly
- ✅ Upload documents
- ✅ Track application status
- ✅ Make payments online
- ✅ Get WhatsApp notifications

**Perfect for:** Families, Small Businesses, Students, and Emergency Needs.

---

## ✨ **Features**

### 👤 **Customer Features**
| Feature | Description |
|---------|-------------|
| 📝 **Apply for Loan** | Personal, Business, Education, Medical, Home, Vehicle |
| 💰 **EMI Calculator** | Real-time calculation with sliders |
| 📄 **Document Upload** | Upload Aadhar, PAN, Bank Statements |
| 📊 **Status Tracking** | Check application status by mobile |
| 💳 **Online Payment** | Razorpay integration for payments |
| 📱 **WhatsApp Integration** | Share application via WhatsApp |
| 📧 **Email Notifications** | Auto-email on application status |

### 👨‍💼 **Admin Features**
| Feature | Description |
|---------|-------------|
| 📋 **Dashboard** | View all applications |
| ✅ **Approve/Reject** | One-click status update |
| 📊 **Reports** | Export CSV, JSON, Excel |
| 🔔 **Notifications** | Send WhatsApp/Email to customers |
| 📄 **Document Viewer** | View uploaded documents |
| 🔒 **Password Protected** | Secure admin access |
| 💳 **Payment Tracking** | View all payments |
